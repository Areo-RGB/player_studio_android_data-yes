# Project Agent Instructions

## Compatibility target

Treat the connected Xiaomi Pad 7 tablet as the only compatibility target for this project.

- Optimize behavior and UI for this tablet's screen, Android environment, storage providers, and available hardware.
- Validate changes against the connected Xiaomi Pad 7 when device validation is requested.
- Do not add compatibility code, fallbacks, layouts, or testing requirements for phones, foldables, TVs, cars, other tablets, or older Android versions unless explicitly requested.
- Keep the existing minimum SDK and build configuration unchanged unless a tablet-specific requirement makes a change necessary.
